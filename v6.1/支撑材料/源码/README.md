程序成功、机器精度闭合或数值稳定性只证明实现层可复现，不证明真实冰崩、泥石流形成、灾害概率或工程安全已经得到验证。

## 3. 运行

在源码目录运行：

```powershell
$env:PYTHONUTF8 = "1"
$env:PYTHONIOENCODING = "utf-8"
& "D:\AppGallery\anaconda\python.exe" .\run_all.py
```

入口以同一解释器顺序执行子步骤，任一步非零退出即停止，并记录 stdout、stderr、源码/输入/输出哈希。主要步骤为：

```text
prep -> 00 -> 04 -> 04b -> 04c -> 01 -> 01b -> 01c -> 02
     -> 02b -> 02c -> 02f -> 04f -> 04bf -> 04bmf
     -> 03 -> 03f -> 06 -> 07 -> v50 -> 05
```

- `prep/00`：附件清点、解压、站点与空间背景。
- `04/04b/04c`：公共断面、一维诊断、D8 路由、有限库存动力与数值验收。
- `01/01b`：边界层、天气过程、极值、静力订正和冲击前单事件旁证。
- `01c`：31 个唯一候选、465 对逐对有效 Spearman 相关、连通簇去冗余、168 h 主榜与 72 h/留一年/2025 伪事件敏感性。
- `02/02b/02c`：完整床面力学、84 沟道状态、冻结水源筛查、时间聚合与共同域空间隔离。
- `03`：2026-08-26 08:00 当地固定发布，使用发布前可用的 06/12/18 UTC IFS 单次起报；每个起报 1000 成员，共 3000 成员，生成源区融化起始代理和同成员 D8 口岸代理到达区间。
- `06/07`：外部响应同日界核验、坐标敏感性与离线哈希归档。
- `v50`：确定性结果验收。
- `05`：当前 JSON/CSV 的 ASCII 键汇总与逐值来源。

断点示例：

```powershell
& $python .\run_all.py --from-step 04
& $python .\run_all.py --only 03
& $python .\run_all.py --skip-fig
```

`--from-step` 不重建其上游；`--only` 是标签前缀过滤；`--skip-fig` 不阻止计算脚本自身生成图件。不得并发运行同一项目。

## 4. 当前模型口径

### 问题一

- 正式候选为 MET 19、RADM 5、SOIL 3、FLUX 4，共 31 个唯一变量键。
- 别名 `Pmax_1h/P`、`ustar/USTAR`、`TKE_obs/TKE` 只保留一个物理候选。
- 事件窗均值相对同积日参照窗中位数形成稳健异常分数；相关聚类逐对计算，不以全候选完全案例替代。
- 正式前五只描述 2026-08-26 单事件相对同季背景的环境特殊性，不是因果效应、发生概率或普适排序。

### 问题二

- 控制体按竖直床厚、单位坡面面积与局部坡度定义。
- 床面力平衡采用无黏聚、无超孔压最小模型，包含上覆水拖曳、床体沿坡自重和有效法向摩擦。
- 机械状态分为 `water_controlled`、`friction_equilibrium`、`gravity_unstable` 和 `not_evaluable`。零门槛状态不计算有限 `T=Q_w/Q_c`。
- v4.3 事件窗标定 `k` 只保存在 `临时产物/审稿记录/v43_旧触发标定审计.json`，正式模型、预报、覆盖和传播均不得读取该值。
- 空间共同域正组不足时返回 `insufficient`，不退回随机像元验证。

### 问题三

- 发布时刻为 `2026-08-26T08:00:00+08:00`，即 `00:00 UTC`。
- 主链使用 2026-08-25 06、12、18 UTC 三次源区 IFS 单次起报；按 6 h 分发上界均在发布前可用。
- 18 UTC 口岸格点文件只作上下文，不进入源区强迫或主传播链。
- 小时预报值使用半开支持 `[t,t+1)`；源区和口岸到达的成员支持宽度均为一小时。
- 源区五类互斥状态为 `finite`、`no_event`、`active_at_issue`、`right_censored`、`not_evaluable`；口岸六类互斥状态为 `finite`、`no_event`、`active_at_issue_left_censored`、`no_arrival`、`right_censored`、`not_evaluable`。两列概率质量分别合计为一。
- 95% 区间是有限成员的条件支持分位；若全为有限成员，则同时作为无条件上界登记。不得把该条件分位改称为经真实频率率定的发生概率区间。
- 真实泥石流形成时刻没有独立真值，因此真实 `t_trig` 覆盖率报 `not_estimable`。口岸冲击仅一个单事件点，10:30 锚点位于条件区间下界之前 36.821 s，覆盖如实报 `0/1`；08:00 报警相对该锚点提前 2.5 h，不能外推为长期预警技巧。
- 空间范围分别报告源区至注入水平距离、注入至口岸中心线距离、源区至口岸直线距离；不同度量不相加。

### 问题四

- D8 是单流向运动波路由，不是全二维水动力；不求横向动量，不模拟真实横向漫淹。
- 16 个配置均为唯一定义情景，不是概率抽样。基准首达口岸代理约 32.77 min，配置范围约 17.57--44.73 min。
- 峰值与终态分场保存。`runout_L_m` 等于分析域末端时只表示右删失分析范围，不是自然停积距离。
- 质量收支、非负、CFL 与时间步细化只作实现层验收，不作物理精度或风险区验证。

## 6. 必须保留的科学边界

1. 源区融化起始是代理目标，不是冰体失稳或真实泥石流形成时刻。
2. IFS 台站至源区迁移、D8 口岸断面吸附和配置情景分布均为结构假设。
3. 单事件环境异常榜不能升级为因果排序或灾害发生概率。
4. 84 历史灾点没有确证非灾对照；“报警日率”不是真实伪警率。
5. 一维诊断和 D8 路由的差异是结构对照，不通过删除未达情景强行一致。
6. 有限库存合成实验只检验机制与账本，不证明现场物源节点或堰塞湖过程。
7. 质量、能量、CFL、非负和收支闭合不是物理正确性的充分条件。
8. 当前结果不支撑工程承载设计、人员伤亡预测或业务预警发布授权。
