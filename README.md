赛题背景：2026-08-26 10:30（UTC+8），高位冰崩引发的「冰崩—碎屑流—泥石流—山洪」链式过程冲击吉隆口岸，冰崩碎屑流壅塞沟道形成堰塞湖并已漫溢。

## 核心立场：可识别性优先

本仓库与同类提交最大的区别在**结果分层**。全文把输出严格分为三层，结论只落在前两层：

1. **计算闭合**——单位、状态、账本、CFL 条件自洽；
2. **模型内条件分布**——在声明的模型集合内成立的成员分布与分位；
3. **真实灾害外推**——需要独立观测才能谈，本次未给出。

由此产生若干刻意的「负结果」，它们不是遗漏，而是结论本身：

- 84 处历史灾点全部是已发生对象，**不含确证非灾沟道**，因此不报告真实发生概率、伪警率或空间 AUC。
- 真实源区冰体失稳时刻 $t_{ice}$ 与泥石流形成时刻 $t_{trig}$ 无独立观测，覆盖率状态记为 `not_estimable`，**不用模型自身生成的越阈标签充当真值**。
- 口岸冲击只有 1 个事件锚点，只能报 `1/1` 或 `0/1` 的个案结果，不构成长期 95% 覆盖率的证据。
- 冰体强度、裂隙、位移、释放历时资料缺失，冰崩发生模型不可识别，问题二输出中保留 `ice_mechanics_unresolved` 事实标签。
- 条件 95% 区间不等于无条件 95% 区间：$\Pr(Y\in I_{0.95\mid\text{finite}})=0.95\,p_{\text{finite}}$，未建立混合分布时输出 `unconditional_interval=null`。

题设对应表用 `status=covered` 与 `evidence_status` 两类字段分别记录「题面要求已映射」与「证据是否成立」，`not_estimable` 是明确结果，不可被改写为 `validated`。

## 快速开始

### 只想读论文

直接打开 [`v6.1/建模论文/main.pdf`](v6.1/建模论文/main.pdf)。正文页脚 1–31，参考文献自第 31 页末起，附录自第 33 页起，共 201 页。

论文结构：绪论（逐问速览）→ 问题分析 → 四问分章（每问含结果卡片）→ 讨论（含「改变当前负结果所需的最小观测」表）→ 参考文献 → 附录（代码清单与文件清单）。

### 想复现计算

源码位于 `v6.1/支撑材料/源码/`，详细说明见其中的 [`README.md`](v6.1/支撑材料/源码/README.md)。要点：

```powershell
$env:PYTHONUTF8 = "1"
$env:PYTHONIOENCODING = "utf-8"
& "<你的 python>" .\run_all.py
```

- 依赖见 `requirements.txt`（numpy 2.3 ／ pandas 3.0 ／ scipy 1.15 ／ matplotlib 3.10 等）。
- 解压附件 3 需 `libarchive-c` 与可加载的原生 libarchive。
- 固定随机种子 `20260826`；不同 BLAS 与求解器版本仍可能产生浮点末位差异，**不承诺跨平台逐字节一致**。
- 原始附件与外部 IFS 响应不入 Git，属可再生产物；请求、时标与 SHA-256 登记在 `v6.1/临时产物/` 的清单中。

## 结论边界

以下表述在本仓库中是被明确禁止的，也是评审时应据以判断的尺子：

- 不能说问题四的结果是「真实灾害重建」——它是在给定体积与地形下的可分情景演算，未经实测流量、流深、流速与物源率定。
- 不能把栅格 D8 路由与几何扇形合称「完整二维水动力仿真」——前者不解横向动量与漫滩扩散。
- 不能用事件窗口内的回顾标定制造「命中」——问题二的水力门槛不使用 2026 事件窗口，问题三的历史回归与残差尺度只用 2021–2025 暖季数据。
- 不能把不同目标（源区失稳／泥石流形成／公共入沟／口岸冲击）的端点拼成同一条「最好看」的时间线。
